# MergeShooting

Unity 6000.3.27f1 기반 머지 + 타워디펜스 플레이 가능 프로토타입입니다.

## 실행

`Assets/Scenes/SampleScene.unity`를 열고 Play를 누르세요.

- 같은 종류·같은 Lv.의 개체 두 개를 겹치면 Lv.1→5로 성장합니다.
- Lv.5 재료 두 개는 기존 135개 제작식으로 다음 티어 Lv.1을 만듭니다. 최고는 T3 Lv.5입니다.
- 유닛을 누르고 `덱 추가/제외`로 중복 없는 최대 5종을 편성합니다. 같은 종류는 보유 개체 중 최고 레벨을 사용합니다.
- `유닛 제작`은 현재 무료이며, 영구 강화의 티어·시작 레벨 확률이 실제 적용됩니다. 미발견 상위 유닛은 나오지 않습니다.
- `영구 강화`에서 골드로 제작 확률을 강화합니다. 최초/과거 저장 변환 시 프로토타입 시작 골드 300을 지급합니다.
- `전투 입장` → 덱 유닛 선택 → 빈 칸 배치 → `전투 시작` 순서로 플레이합니다.
- 아군을 누르면 공격(노란색)·지원(청록색) 사거리와 3개 특성 경로가 표시됩니다.
- 레벨별 특성 한도는 1/1/0, 2/2/0, 3/2/0, 4/2/0, 5/2/0입니다. 세 경로 동시 투자와 두 주 경로는 불가능합니다.
- 10웨이브 동안 처치·웨이브 보상으로 전투 재화를 획득합니다. 전투 종료 후 복귀하면 골드를 저장합니다. 중도 복귀는 보상하지 않습니다.
- 전투는 보유 개체를 소모하지 않고 덱을 복제해 배치하는 프로토타입 규칙입니다. 특성과 전투 재화는 매 전투 초기화됩니다.

## 구현 범위와 현재 한계

공방의 레벨 성장·티어 합성·발견 기록·확률 제작·영구 강화·저장과 전투의 배치·사거리·공격·관통·범위·회복·저지·3경로 구매·웨이브·승패·보상 흐름을 연결했습니다.

90종 공격 프로필과 270개 경로를 JSON에서 읽습니다. 전투 특성은 21개 공통 효과 계열의 단계별 실행 효과를 사용하며, 화면에는 실제 적용하는 효과를 표시합니다. 기획 초안의 캐릭터별 고유 5단계 완성 효과 270개를 모두 개별 실행기로 완성한 상태는 아닙니다. 일부 조건부 능력·지대·정화는 단순화되어 있으며, 아트·애니메이션·전투 밸런스·덱/배치 시너지·장비·기존 전투 성급은 후속 작업입니다.

## 데이터와 저장

- `Assets/Data/game_data.json`: 기존 90종·135개 제작식·적·속성 정의. Excel 변환기로 갱신합니다.
- `Assets/Resources/progression_rules.json`: 최대 Lv.5, 특성 상한, 영구 강화 비용·확률, 배치 비용·웨이브 수.
- `Assets/Resources/combat_profiles.json`: 실제 로드하는 90종 공격/지원 프로필.
- `Assets/Resources/tower_paths.json`: 실제 로드하는 90종 × 3경로 × 5단계 정의.
- `Design/MergeTD_Package`: 상세 기획 초안. Resources 파일이 현재 런타임 입력이며 초안 파일을 편집해도 자동 반영되지는 않습니다.

저장 경로는 `Application.persistentDataPath/main-crafting-v1.json`을 유지합니다. 내부 버전은 v2이며 과거 v1 저장은 개체 Lv.1로 변환하고 과거 제작 경로의 결과 유닛 발견을 복구합니다. 최초 변환을 읽기만 해서는 파일을 덮어쓰지 않습니다. 다음 저장 때 `.bak`을 남기며 저장 실패 시 메모리와 재료를 변경하지 않습니다.

## UI 편집

공방과 전투는 1280×720 가로 기준입니다. 데스크톱·Web 기본 크기와 모바일 기본 방향을 가로로 설정했습니다. 다른 화면 비율에서는 전체 화면이 잘리지 않도록 비율을 유지하고 여백을 둡니다.

공방은 Hierarchy의 `Workshop UI > Landscape Layout`, 전투는 `Battle UI > Battle Landscape Layout`에서 편집합니다. 고정 UI·보드 132칸·사거리 원·적/투사체 표시 풀은 씬에 저장됩니다. 런타임에는 UI 오브젝트를 생성하지 않습니다.

`Tools > MergeTD > Build Landscape UI`(기존 Build Playable Progression UI 메뉴도 동일 동작)는 공방·전투 UI 전체를 가로형으로 다시 작성하는 편집기 도구입니다. 실행 시 해당 도구가 만든 UI를 재배치하므로 직접 수정한 화면을 유지하려면 다시 실행하지 마세요.

## 검증

- `Tools > MergeTD > Verify V2 Database`: 기존 정의 DB 검증
- `Tools > MergeTD > Verify Main Crafting`: 135개 최대 레벨 제작식, 저장 보호
- `Tools > MergeTD > Verify Playable Progression`: 5단계 성장, 특성 상태 전수 검사, 과거 저장 변환, 확률 제작, 90종·270경로 시뮬레이션, 승패 흐름

테스트는 임시 보유 상태와 임시 저장을 사용하며 플레이어 저장을 변경하지 않습니다.
